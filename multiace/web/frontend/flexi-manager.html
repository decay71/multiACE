Flexi — Integrated Mode

Flexi is the fourth MultiACE operating mode

The legacy standalone manager that listened on 127.0.0.1:8767 has been retired and quarantined. It is not part of the active Flexi implementation.

The active implementation runs inside the MultiACE web application and the Klipper [flexi] plugin. Use the operating-mode selector in Config → Initial setup and select flexi. Normal, head and multi remain the original MultiACE modes.

Open MultiACE

Flexi route editing is available without authorizing filament movement. Any physical load, unload or shared-path test still requires an explicit operator approval.
