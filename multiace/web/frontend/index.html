A slot with its own tube straight to a toolhead (no splitter) is not ticked anywhere.

Inlet label is only a name for the hole on the splitter that this slot's tube plugs into, so you can tell the inlets apart on the diagram. It does not change any routing. The default 0:2 is short for ACE 0, slot 2 (ACE number : slot number, the same numbers as in the list). You can rename it to whatever you see on the printer, for example left inlet, top or red tube.
